# Description

IsoFoundry is a free, open-source Windows tool for burning discs, making and checking disc images, and writing bootable USB drives. It aims to match AnyBurn Pro's task-grid simplicity while adding features from other burning and imaging tools, and later the Windows ISO customization from WinISOPilot.

**Short (≤ 80 chars):** Open source disc burning, imaging and bootable USB suite for Windows.

**Medium:** IsoFoundry burns CDs, DVDs and Blu-rays, rips and burns audio, creates and converts disc images, and builds bootable USB drives, all from one compact task grid or the command line.

**Long:** IsoFoundry is a free, open-source (MIT) suite for Windows 10 and 11. Pick a task from a single window: burn images or files to any optical disc, copy discs, rip audio CDs securely to FLAC, MP3 or Opus, burn audio CDs with CD-Text, create, edit, browse, convert and mount disc images, verify checksums, back up large folders across several discs, test disc surfaces, and create bootable or Windows-to-Go USB drives. Every task is also available from the command line. It works offline, collects no telemetry, and asks for administrator rights only for the tasks that need them.
