# Description

IsoFoundry is a free, open-source Windows tool for supported disc, image, audio, backup, and USB workflows. It uses a task grid and command-line tools. Windows ISO customization is a future roadmap item.

**Short (≤ 80 chars):** Open-source Windows suite for discs, images, and bootable USB.

**Medium:** IsoFoundry handles supported CD, DVD, and Blu-ray workflows; creates, checks, and edits supported images; and creates or reads bootable USB images from one task grid and command line.

**Long:** IsoFoundry is a free, open-source (MIT) suite for Windows 10 and 11. Its task grid and command-line tools cover supported optical-disc operations, audio conversion and ripping, backups, image creation and conversion, checksum verification, and bootable USB workflows. Image support includes ISO/UDF, Xbox XISO, raw FAT12/16/32, and fixed or dynamic VHDs containing supported FAT volumes. The USB-to-image workflow can read a physical disk or disk-image file to an image file. Audio encoding supports WAV, FLAC, MP3, and AAC/M4A; Opus and Vorbis are decode-only. Physical optical and USB hardware paths remain unverified; supported formats and other limits are documented in the README and limitations guide. The app works offline, collects no telemetry, and requests administrator rights only for tasks that need them.
