# Screenshot capture list

Real captures from a Windows desktop only — never render or fake
these. Existing captures (main window and the five M1 windows) are
already in this folder and in the README. The windows below still
need theirs; when a capture lands, add it to the README's
screenshot section next to its task.

Framing for all: the whole window, default size, dark theme,
no personal file names visible (use a test folder / the simulated
drive where the window offers one).
